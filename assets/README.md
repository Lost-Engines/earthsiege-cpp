Original Earthsiege 1.0 resource volumes and recorded demo tapes from the supplied October 1994 CD.

These are original game data, not GPL-licensed source code. They are kept byte-for-byte; the developer-released freeware game's assets are included with this project's owner's authorisation. No original game executable is included.

The `demo-clocks` directory supplies estimates for the lift and waits that exceed the recording timer’s range. These use DOSBox captures and, where available, the time between recorded mouse events. Ordinary world updates take their timing directly from the tapes. See [Recorded-input demos](../docs/DEMO_REPLAY.md).
