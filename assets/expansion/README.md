# Earthsiege expansion data

English resources from the March 1995 Mission Disks CD, plus the unchanged
SIMSOUND.VOL from the installed original game. This includes the CD revision of
SHELL0.VOL, whose fourteen font resources differ from the base-game archive
retained by an upgrade installation. The original four expansion input recordings
and KEYJOY.CFG are included for comparison.

Resource loading uses each archive's usage mask and unsigned priority. Original
assets remain in the parent directory, so selecting this edition does not change
base-game data or saves. Executables and installer programs are not needed here.

SHA256SUMS records the shipped bytes. Extraction, inventory and native-executable
checks are documented in earthsiege-reverse/docs/EXPANSION_INTEGRATION.md.
